Install CelikPanel

One command on a clean Linux server downloads the signed release, checks it and installs the panel. Go, Node.js or Git are not needed.

Release
@@CP_RELEASE_VERSION@@, @@CP_RELEASE_DATE_EN@@; signed with Ed25519
Package
One archive for Linux amd64, with its SHA-256 and a signed manifest
Systems
Debian 13, Ubuntu 24.04 (tried on every release candidate)
Debian 12, Ubuntu 22.04, Arch Linux (supported)
amd64
Status
Alpha: for test servers; not ready for production
1

Steps

Start on a clean test server you can reinstall.

Table 1 · Installation steps
StepWhat to doWhere
1Create an account and take a licence for the servercelikpanel.net
2Prepare a clean server with a supported systemYour server provider
3Run the install command; the installer checks the release’s signature and SHA-256 before it installs anythingThe server’s root terminal
4Sign in at the address the installer shows; the setup wizard asks for your domain and where DNS livesThe panel, in a browser

Install command

timedatectl set-ntp true
curl -fL --proto '=https' -o celikpanel-install.sh https://celikpanel.net/get.sh &&
sh celikpanel-install.sh

Run the three lines together in the server’s root terminal. The first line turns on clock synchronisation.

3

Setup wizard

On first sign-in it asks for the main domain and where DNS lives. It shows its plan and changes nothing until you start it.

Table 3 · Where DNS lives
ChoiceWhat happens
This serverThe server keeps its own DNS, with BIND or PowerDNS. One server is enough.
An outside DNS providerNo DNS software is installed. The panel shows the records to add at your provider and what the internet answers for each; it does not write to the provider.
Two servers (optional)The second server keeps a copy of the DNS. It joins with a code that is shown once and is valid for 24 hours. Each server has its own licence.
4

How CelikPanel changes your server

The rules every change follows.

Table 4 · Rules for changes
RuleWhat it means
Confirmation firstEvery change shows what it will do and waits for your confirmation.
Once onlyA repeated click or a resent request never runs a change twice.
One at a timeOnly one change runs on the server at a time; another is refused until it ends.
The system’s own servicesSites, mail, DNS and databases run as the system’s own services and keep running when the panel stops.
Your edits are keptA configuration file you changed by hand is kept; CelikPanel puts its own text beside it and tells you.
Two servicesThe web-facing panel never runs as root. Only the local agent may change the system.
Your password stays on your serverThe first administrator is created on your server; the password is never sent to this website.
5

Already installed?

Update from inside your panel, under Settings, CelikPanel updates. Only the owner starts it; nothing installs by itself. If an update does not complete, the panel puts back the previous version and its database by itself.
