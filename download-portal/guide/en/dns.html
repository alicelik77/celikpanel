DNS for your domain

For everyone

DNS tells the internet where your website and mail are. The domain's DNS tab shows its zone: the list of records that answer for the name.

Where your DNS is served

The DNS tab tells you which of three cases applies:

  • Served by this server. The records are listed and you can change them. Changes are published to the server's DNS service, and to its second server if there is one.
  • DNS is managed at your provider. The domain uses another company's nameservers. The tab lists the values to add there. This list is what is needed, not proof that it is published; the Connecting this domain card on Overview checks the public records.
  • Managed through an authorized CelikPanel DNS connection. Another CelikPanel server holds the zone and publishes your changes.

Adding and removing records

  1. Press Add record.
  2. Choose the Type: A, AAAA, CNAME, MX, TXT, NS or SRV.
  3. Type the Name (@ for the domain itself, www for www.example.com), the Value and the TTL. MX and SRV also take a Priority.
  4. Press Save record.

To change a record, delete it with the bin icon and add it again. Refresh records reads the zone again.

Some records cannot be changed here. A record marked as managed in Server → DNS and peer servers belongs to the server's own setup. If your plan does not include DNS editing, the records are shown but cannot be changed; your provider can add it.

Warning

A wrong A, MX or NS record can take your website or mail offline for as long as the TTL. Note the old value before you delete a record.

Pointing the domain here

The domain reaches this server only after you set it at the company you bought it from (the registrar). The Connecting this domain card on Overview gives the exact values: the nameservers for Route A, or the address records for Route B. See The overview.

What the owner of the DNS servers does

The administrator of the server runs the DNS software (BIND or PowerDNS), chooses the nameserver names and connects a second server, under Server → DNS and peer servers. The second server copies your zone by the standard zone transfer; it needs no CelikPanel action from you.

Nothing has to be reloaded: once the records are published, the tab shows them.

Signing the zone (DNSSEC)

Sign the zone adds DNSSEC signatures. The tab then shows the DS values to enter at your registrar. Enter them last, only after both nameservers serve the signed zone: a DS record entered too early or wrongly makes the domain unreachable for visitors whose resolvers check DNSSEC. If the option is missing, your plan does not include it.
