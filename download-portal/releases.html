Check a download yourself.

The installer does all of this before it installs anything. You can repeat it by hand with standard tools.

  1. Download the package, its SHA-256 file, the signed manifest, its signature and the public key into one folder.
  2. Compare the key’s SHA-256 with the one printed below, then check the package against its SHA-256 file.
  3. Verify the manifest’s signature with the key. The manifest names the package’s SHA-256 and size.

SHA-256 of the release signing public key: 7eadeb0b156f1a821575c4293fe664b44b8004bcdb5e9e770122cb5c144c68bb

Commands

sha256sum release-signing-ed25519.pem
sha256sum -c @@CP_RELEASE_ARCHIVE_NAME@@.sha256
openssl pkeyutl -verify -rawin -pubin \
  -inkey release-signing-ed25519.pem \
  -in release-manifest-v2 -sigfile release-manifest-v2.sig

Each line must end without an error: “OK” for the checksum, “Signature Verified Successfully” for the signature.

Updating an installed panel.

Open Settings, CelikPanel updates in your panel and press Check for updates. Only the owner starts an update; if the new version does not come up, the previous one returns by itself.
