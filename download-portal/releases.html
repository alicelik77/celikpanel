Check a download yourself

The installer does this before it installs anything. You can repeat it by hand.

Table 1 · Steps
1Download the package, its SHA-256 file, the signed manifest, its signature and the public key into one folder.
2Compare the key’s SHA-256 with the one printed below, then check the package against its SHA-256 file.
3Verify the manifest’s signature with the key. The manifest names the package’s SHA-256 and size.

Commands

sha256sum release-signing-ed25519.pem
sha256sum -c @@CP_RELEASE_ARCHIVE_NAME@@.sha256
openssl pkeyutl -verify -rawin -pubin \
  -inkey release-signing-ed25519.pem \
  -in release-manifest-v2 -sigfile release-manifest-v2.sig

Each line must end without an error: “OK” for the checksum, “Signature Verified Successfully” for the signature.

Updating an installed panel

Open Settings, CelikPanel updates, and start the update yourself; only the owner can. If an update does not complete, the panel puts back the previous version and its database by itself. Sites, mail, DNS and databases are not part of it.

Each release’s notes name its commit, say what was tried in the lab and what was not, and list the known limits.
