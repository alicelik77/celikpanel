FTP, SFTP and SSH

Connect to this site’s files with a program such as FileZilla. You sign in as the site’s own account and see only this subscription’s folder; the rest of the server stays closed.

This server accepts only SSH keys for SFTP and SSH. Add a key below; FTP still uses the password.

FTP is not installed on this server, so use SFTP with the same user name and password. Your provider (the server’s administrator) installs FTP; ask them if you need it.

File access (FTP and SFTP)
FTP is always encrypted (FTP over TLS); plain FTP is not offered. SFTP uses the same user name and password and opens no command line.

The command line (SSH) cannot be turned on yet: this server lacks unzip, zip, and the command line takes its tools from the server. FTP and SFTP work.

Your provider (the server’s administrator) installs them; ask them. The option appears here once they are installed. If you are the administrator, sign in with that account: this tab then installs them with one press.
