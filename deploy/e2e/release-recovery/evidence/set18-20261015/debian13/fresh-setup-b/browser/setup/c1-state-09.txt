The certificate uses panel.set18.test. At your DNS provider, point this name to this server’s public IP address and allow time for the public record to resolve.

Checks and how to continue
The Panel restarts once during this setup

At the step “Secure panel access: panel.set18.test”, the Panel gets its certificate and restarts once to start using it. This page then loses its connection for a short time. That is planned: setup continues on the server and this page reconnects by itself. You do not need to do anything.

Once that step has finished, the Panel can also be opened at its secure address: https://panel.set18.test:2083

You sign in again there, and setup shows the same progress. If the browser warns about the certificate at that address, the step has not finished yet, and this page keeps following setup by itself.
