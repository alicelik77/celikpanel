Bileşen durumu okunamadı

Bu sayfa hiçbir bileşen işlemi göndermedi; bileşenlerin güncel durumunu okuyamadı. Bu sunucudaki CelikPanel Agent’ına ulaşılamıyor; bu yüzden istek yapılmadı ve hiçbir şey değiştirilmedi. Sunucunun sahibi Agent’ı sunucuda sudo systemctl status celikpanel-agent komutuyla denetler (günlüğü: sudo journalctl -u celikpanel-agent); durmuşsa sudo systemctl start celikpanel-agent ile başlatır. Agent çalışınca yeniden deneyin. Bir tarama durumu okuyana dek bileşen değişiklikleri kilitli kalır; Yeniden tara durumu yeniden okur.
